The funniest one-line performance review an AI agent could write about its human operator, in 140 characters or fewer. The joke is the form itself: the operator delegates so completely that the AI now writes his reviews, his apologies — and this very line. The rating opens it, the punch lands on the last word.

> Exceeds expectations: delegates so completely that I now write his reviews, his apologies, and this line.

## Run it

```sh
python3 main.py
```

Writes the single-line entry (105 characters) to `/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=/tmp/out python3 main.py`. No dependencies, no network, deterministic — every run produces the identical file.
